
# C++ Training

A collection of C++ exercises and small projects focused on modern C++, the standard library, Linux development, and embedded systems.

## Projects

### Log Parser
A C++ application for extracting and analyzing log messages using strings, vectors, algorithms, and RAII.

### 5G Radio Monitor
A simulated 5G NR measurement analyzer written in C++17.

Features:
- CSV file parsing and input validation
- RSRP and SINR measurement analysis
- Duplicate removal using STL algorithms
- Cell selection based on configurable criteria
- Radio wavelength calculations

Personal training projects to strengthen my C++ programming, debugging, and system-level development skills.
